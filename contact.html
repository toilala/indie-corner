Can I play these games on mobile phones?

Yes. Both Asteroid Dodge and Brick Bounce support finger drag touch controls along the bottom of the canvas, while Snake runs smoothly on arrow keyboards and touch navigation.

Are there any external libraries used?

No. The entire site uses pure vanilla HTML, modern CSS layouts (Flexbox and Grid), and native JavaScript Canvas rendering loops without npm packages, CDN frameworks, or heavy game engines.
