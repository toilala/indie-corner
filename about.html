About Our Indie Corner

We built this website as an open-ended project for our Web Technology coursework. Rather than assembling a generic placeholder template, we wanted to build something genuinely functional and fun: a lightweight hub of browser games powered strictly by fundamental web technologies.

Why We Made It

Many modern websites are weighed down by megabytes of unnecessary client-side packages. We wanted to see how much fun we could deliver using clean, handwritten HTML, responsive CSS with Flexbox and Grid, and modular vanilla JavaScript loops running directly on the native HTML5 Canvas API.

How The Code Is Structured

The project follows strict separation of concerns. Page content and semantic landmarks live solely in HTML, presentation rules and responsive layouts are managed in a single stylesheet, and all interactive game logic and form validation run through an external JavaScript script.
